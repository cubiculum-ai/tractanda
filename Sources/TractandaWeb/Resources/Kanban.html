Why this order

The CLI and item service support an early web kanban, without waiting for learning. The portable LSM and learning workflow remain the next substantial feature sequence.

Move real ACL tests and MCP ahead of the larger clients. That brings agents into the same working system sooner. Add automatic classification once real suggestions and corrections establish useful behavior.

What stays true

  • One independent binary learner per category.
  • Manual decisions keep their authority.
  • Learned state can be discarded and rebuilt.
  • Every client uses the common service.
  • Live edits create item revisions. HTML exports are independent snapshots.
