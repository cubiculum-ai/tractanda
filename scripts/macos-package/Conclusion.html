Open Terminal and run tractanda-tui. Use --profile NAME to select another database. If an unrelated command occupied that name, use the full executable path below.

/Users/Shared/Library/Application Support/Tractanda/current/bin/tractanda-tui

For a new default installation, open the local web example and sign in with your macOS account. An upgrade keeps its previous port. The browser may need a fresh login after restart.
