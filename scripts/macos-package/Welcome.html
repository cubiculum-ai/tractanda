Tractanda

A shared knowledge base for people and agents: immutable items, overlapping categories and contextual views.

This Apple Silicon preview installs the server, terminal client, agent adapter and local Qwen embedding model. It needs no compiler or model download.

A new installation creates a sample database for the currently logged-in macOS user. If Tractanda is already installed, this package upgrades the system's default database and preserves its owner and data. Use the command-line installer for an empty database, another database name or a custom port.

The services run at boot as the existing daemon account. No user or group is created. Software and indexes live under /Users/Shared/Library/Application Support/Tractanda; canonical records live under /Users/Shared/Library/Tractanda/Stores.

This is experimental, source-available software for noncommercial use. Keep backups. The package is signed; notarization is a separate release step.
