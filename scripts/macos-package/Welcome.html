Tractanda

A shared knowledge base for people and agents: immutable items, overlapping categories and contextual views.

This Apple Silicon preview installs the server, terminal client, agent adapter and local Granite multilingual embedding model. It needs no compiler or model download.

A new installation creates a sample database for the currently logged-in macOS user by default. To install software only before joining an existing cluster, choose Customize and deselect “Initialize a sample store”. If Tractanda is already installed, this package upgrades the system's default database and preserves its owner and data. Use the command-line installer for another database name or a custom port.

The services run at boot as the existing daemon account. No user or group is created. Software lives under /Library/Tractanda/Software; canonical records live under /Library/Tractanda/Stores, with per-store indexes under /Library/Tractanda/StoreIndices.

This is experimental, source-available software for noncommercial use. Keep backups. Distribution packages must pass Developer ID signing, Apple notarization and Gatekeeper verification before publication.
